## Deutsch

### Was ist das?
Startdaten für den Freewood-Codex, von Spielern in World of Warcraft: Forever gesammelt: Quests mit Ketten, Kreaturen, Beute, Wege, Schiffe und Zeppeline. Reine Daten, kein eigener Reiter.

### Funktionen
- Wird vom Codex automatisch geladen, wenn der Ordner vorhanden ist.
- Eigene Daten gehen immer vor.
- Wächst mit den Daten, die Spieler in Forever sammeln (der eingebaute Scan des Codex füllt ihn).

### Abhängigkeiten
- Benötigt: –
- Optional: Freewood-Codex (lädt die Daten)

### Befehle
Keine eigenen Befehle.

### Installation
Den Ordner `Freewood-ForeverData` nach `World of Warcraft\_forever_\Interface\AddOns\` kopieren. Neue Dateien lädt das Spiel erst nach einem kompletten Neustart; ein `/reload` genügt nur, wenn sich bestehende Dateien geändert haben. Fehler sichtbar machen: `/console scriptErrors 1`, danach `/reload`.

### Hinweise

- Enthält ausschließlich Daten aus Forever. Daten aus anderen Spielversionen (zum Beispiel OctoWoW) gehören nicht hierher.

## English

### What is it?
Starter data for the Freewood Codex, collected by players in World of Warcraft: Forever: quests with chains, creatures, loot, paths, ships and zeppelins. Pure data, no tab of its own.

### Features
- Loaded by the Codex automatically when the folder is present.
- Your own data always wins.
- Grows with the data players collect in Forever (the Codex's built-in scan feeds it).

### Dependencies
- Required: –
- Optional: Freewood-Codex (lädt die Daten)

### Commands
No commands of its own.

### Installation
Copy the folder `Freewood-ForeverData` to `World of Warcraft\_forever_\Interface\AddOns\`. New files only load after a full game restart; a `/reload` is enough only when existing files changed. To see errors: `/console scriptErrors 1`, then `/reload`.

### Notes

- Contains data from Forever only. Data from other game versions (for example OctoWoW) does not belong here.
